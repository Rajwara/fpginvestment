# public/assets/images/hyatt-lahore/

Photography of Hyatt Regency Lahore. Everything here is served under
`/assets/images/hyatt-lahore/` — a file named `lobby.jpg` is available to the
site at `/assets/images/hyatt-lahore/lobby.jpg`.

Named to match the page route, `/hyatt-lahore`, and the existing
`hyatt-pool.jpg` / `hyatt-terrace.jpg`.

## What the page needs

| Slot | Shape | Notes |
| --- | --- | --- |
| Banner | 1900x1000 or wider | Sits behind a dark scrim, so a wide establishing shot works best |
| Featured | 1600x700 or wider | Full width under the banner — the first real look at the property |
| Two half-width images | 1200x900 | Currently the pool and the terrace |

Anything narrower than about 1200px will be upscaled across the page width and
will look soft. That is the main limitation on this page today: the two images
it uses were cut out of a composite banner, and there is no other photography
of the property in the library.

Interiors, the exterior, a guest room and an F&B outlet would each earn a place
on the page.

## Format

JPEG for photography, at roughly 80–85% quality. Keep files under about 400KB
where you can — a 1600px JPEG at that quality is usually 150–250KB.

## Uploading from GitHub

Open this folder → **Add file → Upload files** → drag the files in → Commit to
`main`.
