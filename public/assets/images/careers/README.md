# public/assets/images/careers/

Images for the Careers pages, served under `/assets/images/careers/`.

- **this folder** — anything for the Careers landing page itself (banner, culture
  and workplace photography).
- **`jobs/`** — images for individual job listings. Name each file after the
  role's slug so it places itself: `financial-accountant.jpg`,
  `acquisition-advisor.jpg`. The slug is the last part of the job's URL.

Nothing here is wired up yet — drop the files in and I will place them. Upload
the best version you have rather than compressing first; I re-encode a `-web`
copy for the site.

Uploading from GitHub: open this folder → **Add file → Upload files** → drag the
files in → Commit to `claude/gallant-dijkstra-eqjoyy`.
