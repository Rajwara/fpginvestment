# public/assets/images/careers/jobs/

One image per job listing, served under `/assets/images/careers/jobs/`.

Name each file after the role's slug — the last part of the job's URL — and it
places itself without anyone having to say which is which:

| Role | File to upload |
| --- | --- |
| Financial Accountant | `financial-accountant.jpg` |
| Acquisition Advisor | `acquisition-advisor.jpg` |

Any new role follows the same rule. WebP or JPEG, at least 1600px on the long
edge; I re-encode a `-web` copy for the site.
