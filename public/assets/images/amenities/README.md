## Format

| | |
| --- | --- |
| Format | WebP or JPEG; WebP is usually half the size at the same quality |
| Size | At least 1600px on the long edge for anything full-width; 1200px for a half-column image |
| Weight | Under about 400KB each |
| Naming | Name each file after the amenity it shows — `banquet-hall.jpg`, `squash-court.jpg` |

Naming files after the thing they show is what made the service banners quick
to place: all six mapped onto their cards without anyone having to say which
was which.
